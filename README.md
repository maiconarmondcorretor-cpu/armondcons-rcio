# Armond Consórcios

Plataforma digital da Armond Imóveis para simulação e futura contratação online de consórcios, com foco principal em consórcio imobiliário, planejamento e construção patrimonial.

## Objetivo

Construir uma experiência premium, mobile-first e orientada à conversão. O fluxo central será: categoria → crédito → objetivo → contato → opções → futura proposta/pagamento/contratação via integração Embracon.

## Categorias
- Imóveis
- Automóveis
- Motos
- Veículos pesados
- Serviços

## Regras comerciais
- Não prometer contemplação, lucro ou valorização.
- Não apresentar consórcio como investimento financeiro com rentabilidade garantida.
- Não chamar consórcio de previdência privada; usar o conceito de planejamento patrimonial de longo prazo.

## Integração Embracon
A integração real será implementada posteriormente. Nenhuma credencial ou endpoint fictício deve ser versionado. A aplicação utilizará uma camada `integrations/embracon` para isolar o provedor.

## Conversão
Objetivo primário: iniciar simulação. Objetivo secundário: gerar lead qualificado. Objetivo futuro: contratação online completa.

## Desenvolvimento e publicação
O GitHub é a fonte de verdade do código. Não publicar automaticamente alterações em produção sem revisão. O Lovable deve ser usado como camada de visualização/publicação quando estiver conectado ao repositório.
